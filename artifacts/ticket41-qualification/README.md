# Ticket 41 qualification record

`release-qualification.json` is the checked-in, intentionally blocked release
record for the Ticket 40 draft candidate. It is an auditable template and
does not claim production settings, provider credentials, human approval,
legal clearance, or production end-to-end evidence. Replace it only with
dated evidence supplied by the responsible operators and publisher; do not
place secrets or Member Data in the replacement.

Run `pnpm release:qualify` for the record-only audit or `pnpm release:check`
for the record plus package, network-trace, and Gate 5 checks. Neither command
submits to the Chrome Web Store.
