# Catalog provenance and bounded platform boundary

The pinned Problem Set Version is imported from
[`neetcode-gh/leetcode`](https://github.com/neetcode-gh/leetcode), commit
`5f9dbb6030c8243c933b799f7999092183d258d1`, data file
`.problemSiteData.json`. It contains exactly 150 records.

The import permits only source code, slug, title, pattern, difficulty,
NeetCode-150 membership, and list order. It excludes problem content,
solutions, explanations, media, site presentation, profile data, submissions,
cookies, and credentials. A Member can open the ordinary public problem URL;
the extension never fetches, scrapes, previews, or verifies that destination.

The complete MIT notice and the exact independent non-affiliation notice are
packaged in `legal.html`, and the source constants are checked by the
publication tests. larp-code is not affiliated with, endorsed by, or
sponsored by NeetCode or LeetCode.

## Residual risk and response

The catalog and ordinary links identify a third-party study list and public
problem destinations. That bounded reference is not a claim of endorsement,
ownership, or permission to copy platform content. If a rights holder objects,
the maintainer will acknowledge the request, preserve the request without
publishing private information, obtain legal review where appropriate, and
pause or remove the affected catalog/link surface while preparing a new pinned
Problem Set Version. This dossier is operational policy, not legal advice or
rights-holder authorization.
